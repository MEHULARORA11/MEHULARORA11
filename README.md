# 💫 About Me:

# 🚀 Featured Projects:

<ul>
<li style="list-style:none;">🔹<a href="https://github.com/MEHULARORA11/Arbiter"><span style="font-weight:750">Arbiter</span></a></li>
<pre>A multi-model LLM orchestrator (Next.js 15) that fans responses out across
five provider adapters over SSE, picks the best answer via a self-consistency
evaluator, and reforms it into a single response. AES-256-GCM encrypted API
key storage, Google OAuth PKCE, and interactive docs built with Excalidraw,
React Flow, and Mermaid.</pre>

<li style="list-style:none;">🔹<a href="https://github.com/MEHULARORA11/QuarkAI"><span style="font-weight:750">QuarkAI</span></a></li>
<pre>A ChatGPT-style streaming chat app on Next.js 16 (App Router) with
Prisma/Postgres-backed persistent conversations, Clerk auth, and per-thread
model overrides. Supports BYOK with AES-256-GCM encrypted DB storage and an
httpOnly-cookie cache layer for fast key resolution.</pre>

<li style="list-style:none;">🔹<a href="https://github.com/MEHULARORA11/PersonicAi"><span style="font-weight:750">PersonicAi</span></a></li>
<pre>A mimicry chatbot (Bun/Express + React/Vite) built on the @openai/agents SDK
that replicates the speaking style of my mentors, Hitesh Choudhary and Piyush
Garg. Ships with Weather, Email, and YouTube search tools, plus per-request
scoped API clients to avoid key race conditions.</pre>

<li style="list-style:none;">🔹<a href="https://github.com/MEHULARORA11/AgentSync"><span style="font-weight:750">AgentSync</span></a></li>
<pre>A Bun/Express + Next.js sandbox for understanding agentic streaming flow
end-to-end, built around the @openai/agents SDK with production-ready SSE
streaming from backend to frontend.</pre>

<li style="list-style:none;">🔹<a href="https://github.com/MEHULARORA11/TalwinderCSS"><span style="font-weight:750">TalwinderCSS</span></a></li>

<li style="list-style:none;">🔹<a href="https://github.com/MEHULARORA11/1-Million-CheckBoxes"><span style="font-weight:750">1-Million-CheckBoxes</span></a></li>
